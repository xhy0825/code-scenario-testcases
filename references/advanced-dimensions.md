# 高级条件分析维度

SKILL.md 第 4 步高级维度补齐引用本文件。**维度 A-D 常规自测默认启用**；**维度 E（MC/DC）与 F（业务链路）在高安全/全链路场景按需启用**。每个维度按其特征识别，生成对应用例。

## 维度 A：数据流 / null 传播

- **识别**：变量"赋值→读取"路径；方法返回值作为下游条件输入
- **规则**：
  - 追踪"值从哪来"：`Order order = dao.findById(id)` 返回 null → 下游 `if (order == null)`——这条链本身是数据流条件
  - 对"返回对象被立即判空"的调用点，补 **null 传播用例**（前置：该调用返回 null，验证下游所有判空分支）
  - 未初始化/局部变量可能为 null 的风险点写入备注
- **示例**：`findById` 返回 null → 传播到 `if (order == null)` 真分支——强调"null 从哪来、传播到哪些下游判断"

## 维度 B：时间 / 时序 / 幂等

- **时间等价类**：`now > expireAt`、deadline、schedule —— 过去 / 现在 / 未来 三段各 1 条
- **时序顺序**：先创建后支付、先校验后提交——操作顺序交换的结果不同
- **幂等/防重**：同一请求重复提交 → 第二次应拦截或幂等成功
- **规则**：对时间比较判定补 3 态用例；对写操作补"重复提交"用例；对关键链路补"乱序操作"用例

## 维度 C：权限矩阵

- **识别**：角色/权限字段（`role`、`hasRole`、`isAdmin`）+ 资源归属字段（`ownerId`、`userId`）
- **规则**：**角色 × 操作 × 资源归属** 矩阵用例——本人 / 他人 / 管理员 × 允许 / 拒绝
- **示例**：`if (user.getRole() != ADMIN)` → 管理员/普通用户 × 本人/他人资源 生成 4 态矩阵
- 若代码无权限校验，已在规则缺口审查标注，此处不重复生成

## 维度 D：容量 / 计算边界

- **容量**：分页 limit、批量大小、上传大小、唯一索引冲突、自增 ID 溢出、集合上限
- **计算**：溢出、精度（浮点金额）、除零、取模、舍入、大数
- **规则**：对容量/数值计算点补 **上限 / 边界±1 / 溢出** 用例；金额类浮点精度列为高风险提示

## 维度 E：MC/DC（高安全场景按需启用）

- **识别**：高安全判定（金额、权限、支付）中的复合条件
- **规则**：**每个原子条件独立改变判定结果** → 每个原子"单独取反时判定翻转"的用例（比拆原子更严格）
- **示例**：`a && b` → (a=T,b=F)→假、(a=F,b=T)→假，两条都生成

## 维度 F：业务链路（全链路场景按需启用）

- **识别**：跨函数/跨服务的关键业务链（创建 → 支付 → 发货 → 完成）
- **规则**：生成完整状态序列用例——每步正常 + 每步失败中断
- **用例量控制**：单链路 ≤ 10 条，超出聚焦关键步骤
