# 外部契约建模（依赖调用五态）

项目代码调用外部服务（DB / 缓存 / 第三方 / 内部 service / DAO）时，分支行为取决于**依赖返回的契约状态**。对每个外部调用点，为每个契约状态生成用例——把"推断（需联调）"升级为**确定性建模**。

## 识别外部调用点

- **命名提示**：`xxxService.`、`xxxDao.`、`xxxRepository.`、`xxxClient.`、`xxxRemote.`、`xxxGateway.`、`xxxApi.` 的实例方法调用
- 框架注入的依赖（`@Autowired` / 构造注入 / import 外部包）调用
- 枚举脚本会对这类调用行打 `external_call` 标记并计入 `dp.json.total_external_calls`

## 契约五态

| 态 | 依赖表现 | 代码应对分支 |
|---|---|---|
| ① **成功-有效** | 返回有效值（true / 对象 / 非空集合） | 正常路径 |
| ② **成功-空/失败** | 返回 null / false / 空集合 / 错误码 | 空值 / 失败处理分支 |
| ③ **抛异常** | 抛业务异常或系统异常 | try/catch 捕获或上抛 |
| ④ **超时** | 调用超时 / 挂起 | 超时处理（若有） |
| ⑤ **降级/熔断** | 依赖不可用 | 降级 / 兜底（若有） |

## 生成规则

每个外部调用点**至少生成 ①②③ 三态用例**；④⑤ 在代码有对应处理时补充。

- 前置条件 = `[mock数据]` + 该依赖被 mock / 返回目标契约状态
- 预期结果 = `UI显示: 无(纯接口);数据结果: <代码对该状态的处理>`（错误串原样摘录 / 推断需联调）
- 用例备注标注 `外部契约：<态>`；优先级按影响面（金额/权限相关 P0）

## 示例

```java
if (!stockService.checkStock(req.getSkuId(), req.getQuantity())) {   // 外部调用点
    throw new BizException("库存不足");
}
```

| 用例 | 用例名称 | 前置条件 | 预期结果 | 备注 |
|---|---|---|---|---|
| TC-001 | 库存校验-成功 | [mock数据] mock 返回 true | UI显示: 无(纯接口);数据结果: 通过，继续下单 | 外部契约：成功-有效 |
| TC-002 | 库存校验-失败 | [mock数据] mock 返回 false | UI显示: 无(纯接口);数据结果: 返回"库存不足" | 外部契约：成功-失败 |
| TC-003 | 库存校验-抛异常 | [mock数据] mock 抛异常 | UI显示: 无(纯接口);数据结果: 按异常处理/上抛 | 外部契约：抛异常 |
| TC-004 | 库存校验-超时 | [mock数据] mock 超时 | UI显示: 无(纯接口);数据结果: 超时处理（若有） | 外部契约：超时 |

> 说明：依赖真实行为需联调确认，但**契约状态本身是确定的**——mock 每个状态、验证代码分支，是自测阶段能做的最大确定性验证。
