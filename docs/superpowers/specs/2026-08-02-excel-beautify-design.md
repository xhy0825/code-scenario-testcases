# code-scenario-testcases Excel 美化与完整显示 设计文档

> **日期**：2026-08-02
> **版本**：v1.22（本设计对应版本）
> **状态**：待实施

## 背景与目标

当前生成的 Excel 已具备基础样式（表头蓝底白字、边框、自动换行、v1.21 场景类型整行着色），但存在两个阅读体验问题：
1. **内容未完全显示**——openpyxl 写入的换行文本在 Excel 中默认行高只有 ~15pt，超出列宽的内容被截断（需要手动拖动行高才能看全）
2. **视觉层次弱**——全表白底无行带区分、优先级无强调、覆盖说明 sheet 分节不醒目

目标：**让 Excel 打开即读、内容换行且完全显示、层次分明**——
- 行高按内容**自适应估算**（中文按 2 个列宽单位、ASCII 按 1，估算换行行数 × 行高）
- 主 sheet **斑马纹**（偶数行浅蓝/奇数行白）+ **优先级着色**（P0 红 / P1 琥珀 / P2 灰）
- 统一字体（微软雅黑）+ 表头行高 + **覆盖说明 sheet 分节标题浅蓝、子表蓝底白字表头 + 行高自适应**

## 设计方案

### 1. 样式常量与辅助函数（模块级）

| 常量 | 值 | 用途 |
|---|---|---|
| `FONT_NAME` | 微软雅黑 | 统一中文字体 |
| `FONT_SIZE` / `HEADER_FONT_SIZE` | 10 / 11 | 数据/表头字号 |
| `HEADER_FILL` | `4472C4` | 表头蓝（主表 + 覆盖说明子表表头） |
| `SECTION_FILL` | `DDEBF7` | 覆盖说明分节标题浅蓝 |
| `BAND_FILL_EVEN` / `BAND_FILL_ODD` | `F2F7FB` / `FFFFFF` | 数据行斑马纹 |
| `PRIORITY_COLORS` | `{"P0":"C00000","P1":"BF8F00","P2":"7F7F7F"}` | 优先级文字色 |
| `SECTION_TITLE_COLOR` | `1F4E79` | 分节标题深蓝 |
| `HEADER_ROW_HEIGHT` / `LINE_HEIGHT` / `MIN_ROW_HEIGHT` | 28 / 16 / 22 | 行高基准（pt） |

辅助函数：
- `_text_width(text)`：显示宽度（中文/全角=2 单位，其余=1）
- `_text_lines(text, width)`：按列宽估算换行行数（含显式换行，留 1 单位余量）
- `fit_row_height(ws, row, width_map)`：按行内容估算并设置行高 = `max(MIN, 行数 × LINE_HEIGHT + 4)`
- `write_section_title` / `write_table_header`：覆盖说明分节标题 / 子表表头统一样式

### 2. 主 sheet（build_workbook）

- 表头：`微软雅黑 11 号 加粗 白字 蓝底`，行高 28，居中
- 数据行：斑马纹填充；场景类型整行着色（沿用 v1.21）；**优先级列以优先级色覆盖场景色**（P0 红 / P1 琥珀 / P2 灰，加粗），使高风险一眼可辨；行高按内容自适应
- 冻结首行 / 筛选 / 下拉（PASS/FAIL、正常/异常流程）不变

### 3. 覆盖说明 sheet（build_coverage_sheet）

- 分节标题：浅蓝底 + 加粗深蓝字（替代原仅加粗）
- 子表表头（场景类型分布 / 功能覆盖 / 追溯矩阵 / 功能↔用例）：蓝底白字加粗居中（与主表一致）
- 全部单元格统一字体 + 边框 + 自动换行；列宽微调（D 列 44→50 容纳长分支）；全表行高自适应

### 4. 优先级列与场景着色的优先级关系（行为细化）

v1.22 起优先级列显示**优先级色**而非场景色——优先级色对场景色的覆盖是**有意设计**：正常绿行中的 P0 显红、异常红行中的 P1 显琥珀，突出"优先测什么"。v1.21 回归测试相应更新为排除优先级列断言。

## 边界与不做

- 不做**单元格底色按场景类型着色**（维持 v1.21 字体色方案，底色留给斑马纹）
- 不做**行高精确像素计算**（openpyxl 无法渲染测量，用显示宽度模型估算，宁高勿裁）
- 不改列数 / 下拉 / 覆盖说明结构（仅样式与行高）
- 不动 `references/*.md`、`evals/`、`enumerate_decision_points.py`

## 验证标准

1. `python scripts/test_generate_excel.py` 全部通过（8 项）
2. 冒烟：真实 xlsx 抽查——表头行高 28、偶数行浅蓝/奇数行白、P0/P1/P2 优先级色、数据行行高 > 最小、覆盖说明全表行高已设置且内容不外溢
3. 行高估算：中文 2 单位 / ASCII 1 单位，纯 ASCII 长串（如代码位置）不再过度撑高
4. SKILL/README 美化说明与实现一致
